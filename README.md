 Customer Lifetime Value (CLV) Prediction & Analytics System

An advanced analytics and machine learning system designed to predict Customer Lifetime Value (CLV). This project processes and analyzes e-commerce transactional data (including insights modeled around multi-platform marketplace dynamics like AliExpress and eBay) to help businesses forecast long-term customer worth and optimize marketing strategies.


 Key Features

Data Preprocessing & Cleaning: Handles missing values, outliers, and formats transactional logs into customer-level summaries.
Feature Engineering: Computes Recency, Frequency, and Monetary (RFM) metrics.
Predictive Modeling: Utilizes machine learning models (such as BG/NBD and Gamma-Gamma, or regression models like XGBoost/Random Forest) to forecast future transactions and value.
Interactive Analytics: Generates visual insights, customer segmentation, and performance evaluation charts.
